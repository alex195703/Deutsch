# Deutsch A1 — тренажер німецької мови

Гра-тренажер колекції «Ігротека» для початківців (рівень A1):

- 📚 **Слова** — 75 тем трьох рівнів (A1/A2/B1), 1 502 слова і фрази з артиклями, множиною, озвучкою та прикладом-реченням до кожного слова; теми розташування у просторі («Місце: тут, там, вгорі») та в часі («Час: спочатку, потім, іноді»); окремі теми обов'язкових побутових фраз («Треба сказати: черга, прохід, транспорт», «Обовʼязково відповісти: реакції»); фільтр за рівнем (браузерний SpeechSynthesis, голос de-DE);
- 🃏 **Картки** — двосторонні фліп-картки з позначкою «Знаю»;
- 🎯 **Вікторина** — переклад урозтріч (німецька ↔ переклад), серія вогників, розбір помилок;
- 🚦 **Артиклі** — тренажер der/die/das з мнемонічним кольоровим кодуванням;
- ⚡ **Дієслова** — відмінювання в Präsens (sein, haben, сильні) + таблиці форм;
- 🗝️ **Модальні дієслова** — усі шість (können, müssen, dürfen, wollen, sollen, möchten): таблиці Präsens/Präteritum з озвучкою, приклади з підсвіченою дієслівною рамкою (Satzklammer), «пастки» вживання і тренування — правильна форма, склади речення, вибір за змістом;
- 👥 **Займенники** — 7 таблиць відмінювання (112 форм) у чотирьох відмінках: особові, присвійні (хто → чий + парадигма mein-), вказівні dieser, зворотні, питальні wer/was, неозначені man/einer/keiner/jeder; кожна форма озвучується тапом;
- 🔗 **Прийменники** — 38 прийменників і сполук у 5 групах за відмінком: завжди Akkusativ, завжди Dativ, Wechselpräpositionen (куди? → Akk / де? → Dat), Genitiv і «дієслово + прийменник»; до кожного — приклади застосування з озвучкою й перекладом, кольорові чипи відмінків;
- 🗣️ **Живі фрази** — побутові формули, реакції, побажання, прислів'я та ідіоми (12 груп: ввічливість, реакції, емоції, побут, магазин, кав'ярня, дорога, телефон, погода, здоров'я) з озвучкою, оглядом і флеш-картками;
- 🧩 **Конструктор** — речення з найчастотніших слів (10 займенників, 16 дієслів, 18 іменників, 16 прикметників, 11 обставин часу) у трьох часах: Präsens, минуле (Perfekt / Präteritum), Futur I — у ствердженні й запереченні, з перекладом і поясненням граматики; режим «Тренувати» — зібрати речення зі слів;
- 📖 **Граматика** — шпаргалка A1: займенники, відмінки, заперечення, порядок слів, модальні дієслова, множина, числа.
- 📕 **Читанка** — 4 книжки (36 розділів) з тап-перекладом кожного слова і глосаріями;
- 🏆 **Прогрес** — ранги A1.1→B1.3, XP, серія днів та 16 досягнень.

Прогрес зберігається у браузері (localStorage). Двомовний інтерфейс:
українська — за замовчуванням, російська — `?lang=ru` або перемикач у шапці.
Джерело мови — лише адреса (без `?lang` сайт завжди відкривається українською).

## Запуск

```bash
bun install
bun run dev        # http://localhost:3000
bun scripts/test-deutsch.ts   # тест даних
```

## Публікація

«Add New → Project → Import» цього репозиторію, налаштування за
замовчуванням (framework автовизначається).
